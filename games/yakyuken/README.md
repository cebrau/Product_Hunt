# 野球拳道場

一頁式的野球拳（猜拳）遊戲，純前端、單一 HTML 檔、無外部相依。直接用瀏覽器開 `index.html` 即可玩。

## 玩法

- 石 勝 剪、剪 勝 布、布 勝 石。
- 喊完「出局！ 安全！ 喲咿呀咿喲！」三拍後同時出拳。
- 每一局輸的一方押上一件裝備（帽、套、棒、球、靴），先失去五件者敗。
- 平手不押裝備，重新喊拳。

原版野球拳輸的是身上的衣服；這裡改成押棒球裝備，內容維持全年齡。

介面、歌詞與喊拳全部為繁體中文。

## 操作

| 動作 | 方式 |
|---|---|
| 出拳 | 點按鈕，或按鍵盤 `1` 石 / `2` 剪 / `3` 布 |
| 重新開始 | 「再戰」按鈕，或結束畫面按 `Esc` |
| 音效 | 「音」按鈕切換（預設關） |

## 對手實力

| 等級 | 行為 |
|---|---|
| 新手 | 純亂數出拳 |
| 老手 | 統計你近八手的出手頻率，六成機率剋你最愛出的那一手 |
| 王牌 | 建立「上一手 → 下一手」的轉移表預測你的下一手，八成機率照預測剋你 |

切換等級會清空對手記下的出手歷史。

## 實作備註

- 檔案開頭宣告 `<meta charset="utf-8">`，即使伺服器沒送 charset 也不會變亂碼。
- 淺色／深色主題都以 CSS 變數定義，跟隨系統設定。
- 尊重 `prefers-reduced-motion`，關閉出拳晃動與印章動畫。
- 音效由 Web Audio API 即時合成，沒有音檔。
